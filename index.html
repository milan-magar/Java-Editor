⌨️ Shortcuts & Tips

Editing

  • Tab Indent the selected lines — or insert 4 spaces at the cursor.
  • Shift+Tab Outdent the selected lines.
  • Ctrl/Cmd+/ Toggle // line comments on the current line or selection.
  • Ctrl/Cmd+D Duplicate the current line or the selected block.
  • Alt+↑/↓ Move the current line (or selected block) up / down.
  • Enter Auto-indent. After a { an extra level is added, and typing Enter between {} expands into a block.
  • ( [ { " ' Auto-close the pair — or wrap the current selection in the pair.
  • Backspace On an empty pair (e.g. | inside ()) deletes both characters at once.

File & Folder

  • Ctrl/Cmd+S Save to your chosen folder. Asks for a folder the very first time.
  • Ctrl/Cmd+Shift+S Save As… — write to a different location with the native file dialog.
  • 📁 Click the folder button to choose or change the save folder. Your choice is remembered between visits.
  • Open Load a .java file from disk into the editor.

File name

  • auto The file name follows the public class (or interface, enum, record) in your code, so javac is always happy.
  • type Type in the File field to override the name manually. The auto badge disappears.
  • clear Clear the File field to re-enable automatic tracking.

Editor

  • Selection Selections are semi-transparent so the syntax colours stay readable underneath.
  • A− A+ ☀️ Adjust font size and switch between dark / light theme — all remembered locally.
  • Copy Copy the whole buffer to the clipboard in one click.
  • F1 Open this cheat sheet. Press Esc or click outside to close.
💡 Tip: Your code, file name, theme, font size, and chosen folder are all saved locally, so the editor picks up exactly where you left off — even after closing the tab.
